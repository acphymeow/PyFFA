# 周期纵向坐标连续化：最终写作口径与内部记录

更新时间：2026-08-24

本文件记录 Referee A Comment 1 对应的最终处理口径，包括审稿人真正关心的问题、论文正文建议稿、合并后 Fig. 5 的图注，以及与演示脚本之间的关系。论文正文应采用读者视角描述算法，不写代码演变过程，也不展开“一次或多次建 bins”等实现讨论。

## 1. 审稿人关心的三个问题

审稿意见的重点不是程序怎样组织，而是以下三个物理和算法问题是否说清楚：

1. 当谐波数 \(h>1\) 时，如何区分多个已占据的 RF buckets，并把每个束团恢复为连续纵向区间；
2. 少量远离束团主体的尾部或 halo 粒子是否会把纵向区间异常拉长；
3. 图中标出的 occupied interval 是否与实际粒子范围一致，区间之外的粒子是否仍参与空间电荷计算。

因此，正文的逻辑顺序应当是：

> 周期投影 → 降低零散尾部对边界判断的影响 → 确定公共切口和束团边界 → 分别确定各束团的主要切片范围 → 保留并处理范围外的尾部粒子。

## 2. 核心方法

纵向区间由纵向密度直方图的 bins 确定，而不是由最外侧的个别粒子散点直接给出。这是本次说明的核心。

这一处理同时回答了 halo 和 \(h>1\) 两个问题：

- 对 halo：零散的低密度粒子不形成连续的束团密度区域，因此不单独控制公共切口、束团边界或主要切片范围；
- 对 \(h>1\)：束团之间的低密度间隔可用于选择一个公共切口，并确定其余束团边界，使多个已占据的 RF buckets 分别形成连续区间。

这里的“主要密度区域”比“核心密度 bins”更适合写入论文。若必须说明其数值定义，可写为：在每个束团中，按纵向密度选择累计包含预设电荷比例 \(q\) 的 bins，并以这些 bins 的左右外边界确定一个连续区间。本文演示和验证采用 \(q=0.995\)。

## 3. 面向读者的算法步骤

1. 将粒子的方位角投影到一圈周期坐标，并统计纵向密度分布；
2. 根据平滑后的密度分布区分连续的束团分布和零散的低密度尾部，使少量 halo 粒子不控制间隔和边界的判断；
3. 在束团之间寻找低密度间隔，将最宽间隔选为公共切口；当 \(h>1\) 时，其余间隔作为相邻束团之间的边界；
4. 从公共切口处展开周期坐标，使每个已占据的 RF bucket 对应一个连续束团区间；
5. 在每个束团中，以包含预设电荷比例 \(q\) 的主要密度区域确定常规纵向切片范围；
6. 主要范围前后的粒子分别进入头部和尾部两个边缘切片。它们不参与边界的确定，但仍参与电荷沉积、场求解和场插值；
7. 横向空间电荷场在每个纵向切片内独立求解；纵向空间电荷场由同一束团的全部纵向切片共同确定，并对不同束团分别计算。

正文不必给出总切片数，也不必写成“\(1+126+1\)”。读者只需要知道：主体区域采用常规切片，前后尾部各由一个边缘切片接收，所有粒子都保留在计算中。

## 5. 论文 Section IV B 中文建议稿

### B. 连续纵向坐标的构造

纵向区间根据纵向密度分布确定，而不是由最外侧的个别粒子直接给出。首先将粒子的方位角投影到一圈范围内，并统计其纵向密度。如果束团跨过原来的 \(0/2\pi\) 边界，同一个束团会出现在周期区间的两端，因此不能直接用于纵向切片。

在寻找周期切口之前，先根据纵向密度区分连续的束团分布和零散的低密度尾部。少量远离束团的尾部或 halo 粒子不用于判断束团的位置和边界，但仍保留在粒子分布中，继续参与后续计算。这样可以避免个别远端粒子影响公共切口和束团边界的选择。

随后，在纵向密度分布中寻找束团之间的低密度间隔，并将其中最宽的一个选为公共切口。对于 \(h=1\)，坐标从该切口处展开后得到一个连续束团。对于 \(h>1\) 且有多个 RF buckets 被占据的情况，其余低密度间隔作为相邻束团之间的边界。展开后的纵向坐标由此被分成多个连续束团区间，每个区间对应一个已占据的 RF bucket。

完成束团划分后，在每个束团区间内分别确定主要切片范围。本文将包含预设比例 \(q\) 束团电荷的主要密度区域作为束团主体，并用其两端确定纵向切片范围。本文计算采用 \(q=0.995\)。位于该范围前方和后方的尾部粒子分别进入两个边缘切片。这些粒子不会被删除，仍然参与电荷沉积和空间电荷场计算。

最后，将展开后的方位角坐标转换为沿闭轨的纵向距离。横向空间电荷场在每个纵向切片内独立求解；纵向空间电荷场由同一束团的全部纵向切片共同确定，并对各个束团分别计算。

## 7. 内部实现记录

### 7.1 单次建立并复用全环 bins

演示脚本只在 \([0,2\pi)\) 上建立一次周期直方图：

\[
\phi_{\mathrm{mod},i}=\phi_i\bmod 2\pi.
\]

公共切口对齐到已有 bin edge。坐标展开通过循环移动同一组 counts 和 bin edges 完成；各束团只截取对应的 bin 区段，不再重新建立局部直方图。因此，“全环一次建 bins”和“逐束团复用这些 bins”是同一个实现过程。

### 7.2 主要密度区域

对第 \(k\) 个束团，将非空 bins 按平滑密度从高到低排列，并累计原始粒子数，直到达到 \(qQ_k\)。最左和最右入选 bin 的外边界定义连续主要区间。两端之间即使存在内部低谷，也不会把同一束团错误地分成两段。

### 7.3 尾部粒子

未进入主要密度区域的粒子没有被删除。主体区间前后的粒子分别进入两个边缘切片，并继续参与：

- 电荷沉积；
- 横向和纵向空间电荷场求解；
- 场插值回粒子。

因此，密度筛选只用于稳定地确定边界和常规切片范围，不是粒子筛除。

### 7.4 适用条件和状态边界

当前离线构造验证的是全部 \(h\) 个 RF buckets 均被占据，且相邻束团之间存在可识别低密度间隔的情形。部分填充需要额外识别空 bucket，不能简单要求得到 \(h\) 个束团区间。

这一实现状态只保留在内部记录中。论文和审稿回复聚焦算法如何处理 \(h>1\)、halo 和区间一致性，不主动展开代码版本或开发过程。
