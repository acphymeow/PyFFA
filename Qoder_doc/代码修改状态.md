## Emap 预处理的 SEO 路径解析（2026-11-17）

`examples/main_Emap.py` 的 `resolve_seo_dir(Emap)` 统一解析 SEO 数据目录，频率曲线生成中读 `SEO_r.txt`（spiral 分支）与 `SEO_ini.txt` 的两处都经它取路径。规则为严格模式，无回退：

1. SEO 目录只按 `Bmap_fold/SEO_folder` 拼接；两个键都必填，缺键抛 `KeyError`；
2. 该目录下没有 `SEO_ini.txt` 时抛 `FileNotFoundError`，消息给出完整路径；
3. 不接受把 `Bmap_fold` 直接写成 SEO 目录的旧写法，这种配置现在会报错。

`examples/config_Emap.py` 当前值：`Bmap_fold = './Bmaps/Bmap_test'`（相对项目根目录，与 README 的运行约定一致），`SEO_folder = 'resultsSEO'`（必填，无默认值）。SEO 子目录名不是 `resultsSEO` 的机器（例如历史目录 `resultsSEO_noError`），必须在配置里显式写 `SEO_folder`。
