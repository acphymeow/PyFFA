## Emap 预处理的 SEO 路径解析（2026-11-17）

`examples/main_Emap.py` 的 `resolve_seo_dir(Emap)` 统一解析 SEO 数据目录，频率曲线生成中读 `SEO_r.txt`（spiral 分支）与 `SEO_ini.txt` 的两处都经它取路径。解析顺序：

1. `Emap['Bmap_fold']` 本身含 `SEO_ini.txt` 时直接用它（兼容旧配置把 Bmap_fold 写成 SEO 目录的写法）；
2. 否则用 `Bmap_fold/Emap['SEO_folder']`，`SEO_folder` 缺省为 `resultsSEO`；
3. 两者都没有 `SEO_ini.txt` 时抛 `FileNotFoundError`，消息列出尝试过的路径。

`examples/config_Emap.py` 当前值：`Bmap_fold = './Bmaps/Bmap_test'`（相对项目根目录，与 README 的运行约定一致），`SEO_folder = 'resultsSEO'`。SEO 子目录名不是 `resultsSEO` 的机器（例如历史目录 `resultsSEO_noError`），必须在配置里显式写 `SEO_folder`。
